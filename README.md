# HealthGrid Frontend

A soft, responsive React + Vite + Tailwind CSS prototype based on the uploaded HealthGrid concept brief.

## Included MVP screens/features
- Facility dashboard
- Medicine inventory table
- Short-term demand forecasting visualization
- Stock-out risk alerts
- Resource redistribution matching suggestions
- Facility network
- Analytics
- Administrator report / print-to-PDF
- Prototype settings
- Search, responsive sidebar and facility detail modal
- Clearly labelled synthetic prototype data
- Human-in-the-loop / decision-support messaging
- Recharts visualizations

## Run
```bash
npm install
npm run dev
```
Then open the Local URL shown by Vite (normally http://localhost:5173).

## Scope note
This is a frontend-only demo. It uses local synthetic data and does not connect to FastAPI/PostgreSQL yet. Backend APIs, live maps, real facility integrations, autonomous transfers, clinical diagnosis and production federated learning are not implemented in this frontend prototype.
